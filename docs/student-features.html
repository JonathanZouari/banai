כללי הברזל

  • מצב אחד. כל שינוי בעיצוב הוא רשימת ops טהורים, (design) → newDesign, בלי מוטציה. התלת־ממד רק מצייר מה־state.
  • Parity. אם משנים op בצד אחד, משנים אותו גם בצד השני ומוסיפים fixture ב־shared/fixtures/ops/.
  • AI תמיד דרך אישור. הסוכן מציע הצעה חתומה, והמשתמש לוחץ Confirm. אין שינוי אוטומטי.
  • יחידות. כל האורכים במילימטרים שלמים.
  • Stack. Vanilla JS + Three.js, ו־FastAPI + Pydantic. בלי React או Vue.
  • אסור לבנות: מחירים או הצעות מחיר, הזמנות, חשבונות משתמש, דשבורדים, ייצוא CNC או רשימות חיתוך, עיצוב חדר, העלאת תמונות, ו־drag-and-drop של גאומטריה. האפליקציה אף פעם לא טוענת שעיצוב ניתן לייצור.
  • Git. עובדים על branch משלכם (feature/<שם>) ופותחים PR ל־dev. לא נוגעים ב־main.
